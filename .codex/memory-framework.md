# 记忆使用方法

本说明及共享偏好、专业方法由 GitHub `york6668/codex-framework` 维护和发布；Mac mini 上的说明是部署副本。Mac mini 等执行节点各自保存历史记忆，记忆数据与方法源码分开管理。读取本地记忆不会将它上传到本仓。

- 优先遵循当前用户要求和现行 `AGENTS.md`。历史记忆用于找到已有决定、资料和线索，不把旧状态作为执行权限或业务事实。
- 当前问题依赖先前决定、项目约定或历史结果时，先从客户端提供的记忆摘要与索引定向查找，再按引用读取必要的来源。自包含的简单问题不必查记忆。
- 旧结论可能变化时，按影响核验当前代码、配置或实际结果；尚未核验的历史信息明确标注来源与时效，不冒充当前事实。
- 优先使用客户端提供的记忆位置。默认发现入口为 `${CODEX_HOME:-$HOME/.codex}/memories`；不同版本可能使用其他目录，按客户端实际注入的信息处理。不存在记忆时继续当前工作，不创建虚假的历史或复制其他设备的数据。
- 原生记忆由客户端生成和管理；用户要求补充或纠正时，优先使用该客户端支持的入口。本机文件记忆允许的人工补充放在客户端指定的 notes 位置，不手工覆盖生成的索引与摘要。记忆中不保存凭据。
- Codex 云端执行环境可安装本 GitHub 项目的规则和 Skills。是否支持原生记忆、何时生成记忆，由目标客户端决定；安装本框架不代表该执行环境获得了 Mac mini 或其他节点的历史记忆。

可选配置在 [memory-settings.example.toml](memory-settings.example.toml)。当前本机使用的两项配置被保留为示例；同步工具仅分发这个文件，**不会改写 `config.toml` 或自动开启记忆**。在新设备上使用原生「个性化 → 记忆」或该客户端支持的配置入口，保留设备已有选择。

官方说明：[Memories](https://learn.chatgpt.com/docs/customization/memories)。
