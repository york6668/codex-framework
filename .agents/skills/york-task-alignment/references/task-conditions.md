# 原任务的普通条件、停止与拒绝

在原任务或业务记录中分清 dependency、capability、business_failure、user_stop 与真实权限拒绝；复用已有身份、字段及写入机制，不要求统一 schema、另建任务库或登记普通会话。不能从自然语言、字段名或旧索引标签猜测拒绝来源。

普通条件只限制对应步骤及已证依赖消费者。保留原请求/输入、步骤或对象、责任、条件来源与修订及实际缺失证据；同一条件沿原身份更新，不反复登记。业务失败交原责任诊断，能力不足等待准确能力，依赖缺失等待对应输入；都不能无限搁置独立获准工作。

用户停止优先于普通条件满足，只能由适用的直接用户恢复解除。平台拒绝按原对象、目的地和副作用保留，原生工具决定实际动作权限；owner 标签、报告或方法文档不授予权限。UNKNOWN 先核原执行、原效果和原结果，不补发、清占用或把超时当未执行。

## 核实满足并接续

原责任读取真实返回，核对当前请求与输入修订、具体条件、对象/节点/版本、来源及观察时间，确认它消除了哪一个缺口。报告必须可追溯到实际原件；旧输入、别的对象、仅文件出现或时间过去，均不自动解除当前条件。重新读取不会刷新源事实，新鲜度按本次动作的实际需要判断。

满足的普通条件由原责任在原权威更新并读回，仅解除该条件；其他条件、停止、拒绝、UNKNOWN 和已有成果继续保留。使用已有 CAS 等一致性能力时按准确原修订操作，冲突先重读；不为这一步新增门禁或恢复已归档接口。

写入或回执不明，先核实际记录及原效果；已提交就消费其结果，未核清不重复领域动作。已完成效果仅在原输入与对象仍适用时复用，变化回到原责任判断，不自动重放。条件解除后，在当前真实回合推进获准后继；文档、程序校验或文件更新不提供后台执行机会。

## 已归档 Task Store

旧 `task` 命令和执行链已退出当前安装包。原记录、原结果、历史代码/版本包及拒绝、UNKNOWN 保持原位；按明确来源读取原件，把仍有效义务交现有原生任务和原责任承接，不将旧状态迁入另一份权威表。

历史 external_condition 等未分类字段可能表示等待或取消；未核原来源不能重分类或清除。已受拒的 TaskStore/effects 核收写回不能通过新任务、改路径、其他工具或新条件 ID 重试。历史源码可从原仓已发布版本找回，但可恢复不代表获准执行，也不要求当前包保留整套旧链路。

源码关系校验、实际权限、原责任对条件的判断及最终效果分别取证；历史 pending 或 accepted 标志不能独自决定当前需求是否完成。
