# 按需读取原件上下文

适用于原系统 JSON 已承载需求、来源、任务或结果，完整展开会带入大量无关正文的场景。原记录继续持有事实；不复制知识库、事件台账、授权库或调度状态。来源角色、适用对象、修订时刻及允许回传内容由原记录和实际授权判断，字段名或内容 hash 不认证身份。

先选与当前判断有关的原件及字段，再读取所需正文。结构目录只表示发现了字段，不能据此断言已经读懂要求、核收结果或证明未读部分没有阻断。判断依赖的原目标、修订、失败、拒绝和未知效果必须读到；按需读取不能成为遗漏这些内容的理由。历史状态仍按其源时刻解释。

维护仓库的 `scripts/obligation_projection.py` 提供可选 `--read` 入口，复用已有 JSON pointer 和唯一精确 ID 选择，不要求原文件改成统一 schema：

```sh
python3 scripts/obligation_projection.py /path/to/original.json --read '#/tasks'
python3 scripts/obligation_projection.py /path/to/original.json --read '#/tasks/0/source'
```

对容器只返回直接子项的 pointer、类型、大小和内容 hash，不输出子项正文；继续读确切字段才取得其值。文本按最多 1000 个 Unicode 字符分页；容器默认每页 20 项，可用 `--page-size 1..50`。每次输入限制为 8 MiB，完整 stdout 限制为 16 KiB；容器页会按输出字节缩小，无法容纳的单项明确报错，不能用静默截断代替。原有 `--frontier` 完整展开行为保持原样，不受这些可选读取边界保护。

返回的 `next_cursor` 非空时，以相同文档和 `--read` 选择传入 `--cursor` 接续。游标绑定所读文件路径、原始内容 hash 及已解析 pointer；任何源字节变化都要求重新读取，避免文件变化时跨页漏项。相同快照重复读取仍返回同一页，不登记“已读”或消费任务，也不提供执行去重。游标只作一致性核对，不能当作访问凭据或签名。

已取得某个字段后，可在下一真实回合使用 `--if-value-sha256 <上次该值的 hash>`；相同内容返回 `unchanged`，避免重复正文。它仅指所选字段，仍返回当前源 hash，不表示整个文件、需求、权限、任务进度或平台状态未变化。容器对象键重排不改变值 hash，但会使旧分页游标失效。游标接续和 unchanged 检查分开调用。

调用者继续使用原生任务记录定位新消息、真实 turn/item 和原结果，不从该工具推导唤醒、授权、已送达、语义采用或任务完成。工具只打开明确传入的文件，不追随文档内其他文件/URL 引用，不写回原件、不自动轮询，也不接入模型 API。大文件或过长字段名超出边界时在原节点缩小获准读取范围；不为让工具通过而复制全部私人资料进核心仓库。

本地读取、进入模型、跨聊天和公开发布仍分别核对。目录中的字段名和 pointer 本身也可能包含受保护信息，元数据模式不是私密识别器；只能对已获准的对象和目的地使用。该入口作为维护源码由当前执行者显式调用，不在受管 CLI 模块包中，也不证明其他任务已经采用。
