# 可选 dbctl 实现

仅在当前节点实际存在适用的 `dbctl` 时参考本页；框架不分发或强制依赖某套 dbctl。旧 `$HOME/docker/mi-local` 只可作为发现线索，其不存在不影响按 [通用同步方法](data-sync.md) 选择或补齐本机实现。

先读实际工具目录中的 README、帮助和必要源码，确认当前版本的连接来源、支持服务、对象选择、覆盖方式、容量与恢复能力。同名命令不证明不同节点采用相同实现，旧记录不证明今天支持相同参数或行为。

| 能力 | 使用前按当前实现确认 |
|---|---|
| 状态、日志、容量与已有报告 | 区分当前只读状态与历史快照；容量统计是否覆盖所需服务及现存对象。 |
| 环境启动、停止、重启或自测 | 是否初始化或写入夹具，是否会影响未指定服务；核对实际 Docker daemon、Compose 和消费者。 |
| 源对象发现与同步 | 是否会保存清单或改写本地规则，实际支持哪些选择器，是否替换表、集合或整个 Redis DB；不能默认存在按 key 同步、全量选项或覆盖前备份。 |
| 失败恢复 | 实际检查点、重试粒度及是否跳过已完成对象；续跑所沿用的源、范围、窗口和容量限制。 |

若外层帮助未显示同步细项，从实际入口与源码定位子命令，不照搬历史脚本路径。优先复用工具自带客户端环境与已验证连接；测试源到本地同步能力不代表支持向测试环境写入，生产查询仍沿既有渠道。

框架的生命周期与需求范围优先于旧工具默认；工具不足以完成当前需求时由节点调整或选用其他实现，保留真实限制和核验结果，不以工具成功替代业务完成。
