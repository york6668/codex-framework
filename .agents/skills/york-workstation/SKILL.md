# Codex 工作站

发现已有工具与服务，优先复用；缺少能力时按任务需要补齐。工作站承载可跨任务保留的资源，当前任务维护目标、计划和进度。

- 当前 `${CODEX_HOME:-$HOME/.codex}/workstation/README.md` 工作站入口 提供本机资源位置；以当前工具、进程、端口、标签与实际连接核验可用性。
- 对用户已委托或在授权任务中创建的本机资源，按需自主安装、配置、启动、修复、扩容和替换，不限 Docker、数据库或任何服务清单。既有授权持续有效；安装机制与工具合同仍适用。
- 持久资源任务结束后保留。共享资源变更核对实际消费者；未知资源先辨识，不能因可访问就接管。服务管理权与其中数据的处置范围分开判断。
- 已有环境满足需要时直接使用，不增加工作站准备步骤。维护随任务需要执行，不自动建立巡检或每任务登记。

## 按当前需要加载

- 新资源、共享服务、升级或清理：[资源生命周期](references/resource-lifecycle.md)。
- 现有 Docker / Compose / dbctl 的服务与容量操作：[本机服务入口](references/local-services.md)。
- 私有依赖、日志入口的网络要求或连接故障：[本机网络](references/local-network.md)。
- 业务数据选择、导入及同步恢复使用 [本地数据方法](../york-local-data/SKILL.md)；数据库就绪不代表数据或业务断言通过。
