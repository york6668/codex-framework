# 同一契约反复出错时的回源

用户要求回顾记录，或相同语义边界反复失败时，从相关索引及直接引用开始读取历史。相同任务的摘要、引用和转述去重，按实际语义边界和失败原因归纳，次数不是证据强度。

历史帮助找到候选原因和入口。采用旧结论前回读当前生产者、转换、持久化及消费者代码，或相关协议、配置与原始运行结果，核对主体、版本和适用范围。新证据否定旧前提时调整对应方案，不恢复已解决阻断，也不把一次错误路径沉淀为永久禁令。

保留代表性来源、当前核验与仍缺证据即可。稳定业务语义回到承担该责任的仓库；可复用的方法缺口交给 [规范维护](../../york-codex-policy-maintenance/SKILL.md)；涉及当前方案与重要纠偏时按 [任务对齐](../../york-task-alignment/SKILL.md) 维护唯一记录。仍有效的用户要求不因来自较早对话失效；查阅历史不授权更新记忆或建立跨任务台账。
